Processo de Criptografia Híbrida (PGP-like)
  1. Assinatura: Mensagem original assinada com chave RSA privada do remetente (autenticidade).
  2. Chave Simétrica: Gera chave AES-256 aleatória para esta mensagem (eficiência).
  3. Criptografia: Mensagem cifrada com AES-256 (rápida para texto longo).
  4. Proteção da Chave: Chave AES cifrada com RSA pública do destinatário (confidencialidade).
  5. Integridade: Hash SHA-256 da original para verificar alterações.
End-to-End: Apenas remetente e destinatário podem ler.

Como funciona: Ambos os usuários calculam a mesma chave compartilhada usando suas chaves privadas DH e as chaves públicas DH um do outro, sem nunca trocar as chaves privadas. Essa chave é usada para derivar chaves AES seguras para mensagens futuras.
Segurança: Chaves privadas nunca saem do dispositivo. O acordo DH resiste a ataques Man-in-the-Middle se chaves públicas forem trocadas via canal seguro (ex: TLS/HTTPS).
